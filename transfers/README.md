# Transfers website

React + Vite + Tailwind landing page for a private airport transfer service.

## Run it
1. npm install
2. npm run dev
3. Open the local URL shown in the terminal

## Customise
Edit the constants at the top of src/App.jsx:
- BRAND, WHATSAPP (country code + number, no + sign), PHONE, EMAIL

Brand colours live in tailwind.config.js (ink and taxi).

## Deploy
Push to GitHub and import into Vercel. Build command: npm run build, output: dist.
